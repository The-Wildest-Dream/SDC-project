description: 用户明确的业务优先级和未实现功能展示规则

项目重点是价格分析与报价决策，库存提醒和客户付款记录是辅助功能。
保留 Python + Streamlit 及能运行的报价计算器。
尚未实现的页面明确标注“待实现”，不要使用虚假的统计数字、成功提示或无法执行的按钮冒充已完成功能。
全部使用团队生成的合成数据，并明确标注“模拟数据”。用户已授权接入Replit内置PostgreSQL持久化，保留Python + Streamlit。
同一产品、币种和计量单位的数据才能直接比较。
客户付款表现不称为“诚信判断”，不自动决定授信、账期或先货后款；样本不足明确提示。

**Why:** 用户明确要求。

**How to apply:** 后续扩展遵循以上业务优先级；页面占位与实际可执行功能要明确区分。
